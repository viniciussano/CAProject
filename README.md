# 🏨 Hotel Reservation Management System

## 📌 Overview
This project is a **Hotel Reservation Management System** developed to help hotels efficiently manage, track, and organize guest reservations.

---

## 🏗 Architecture
The application follows a **three-layer architecture**:

- **Presentation Layer**  
  Windows Forms (WinForms)

- **Business Logic Layer**  
  C# classes handling validation, rules, and application logic

- **Data Access Layer**  
  SQLite database for persistent storage

---

## 🚀 Features
- User authentication (login system)
- Guest management
- Room management by type and capacity
- Reservation creation, search, update, and deletion
- Room availability validation based on dates
- Automatic price calculation based on stay duration
- Sorting and searching reservations
- Data persistence using SQLite

---

## 🛠 Technologies Used
- **Language:** C#
- **Framework:** .NET Framework 4.7.2
- **UI:** Windows Forms
- **Database:** SQLite
- **IDE:** Visual Studio 2022 (Community Edition)

---

## ⚙️ Requirements
To run this project, you need:

- Visual Studio 2022 with **Windows Forms App (.NET Framework 4.7.2)**
- SQLite installed
- **SQLite/SQL Server Compact Toolbox** *(optional — for database visualization)*

---

## ▶️ How to Run
1. Clone or download this repository
2. Open the solution file (`.sln`) in Visual Studio
3. Restore NuGet packages if prompted
4. Build the solution
5. Run the project (`F5`)

The SQLite database will be created automatically on first run.
